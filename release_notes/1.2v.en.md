## Download

| File | For |
|---|---|
| `Wasl-1.2-arm64-v8a.apk` | **Most phones** (2017 and newer) — pick this if unsure |
| `Wasl-1.2-armeabi-v7a.apk` | Older or low-end phones |
| `Wasl-1.2-x86_64.apk` | Emulators and Chromebooks |
| `Wasl-1.2-universal.apk` | Any device (larger download) |

All variants share the same version code, so you can update from any of them to any other.
Android 7.0+. Verify with `sha256sum -c SHA256SUMS.txt`.

## What's new

- **English UI** — the app now speaks Arabic and English. By default it follows the phone (Arabic if the phone is in
  Arabic, English otherwise); switch it any time in *Settings → Language*. Notifications and the fingerprint prompt
  follow the same choice, and the layout flips to left-to-right in English. On Android 13+ the language also shows
  up in the system's per-app language settings.
- **About card** in Settings: app name and version shown clearly, plus a link to the source code on GitHub (tap to
  open, long-press to copy).

## Fixes

- Long-pressing a message: when there were many options (e.g. an admin in a group) the last one, *Delete for
  everyone*, was cut off and couldn't be reached. Option sheets now grow and scroll. The same fix applies to the chat
  menu on the home screen, mute, attachments and the blocked list.
- The "open" chevron on settings rows now points the right way.

## Notes

- System messages saved before this version (e.g. "X joined the group") keep the language they were written in; new
  ones use the current language.
- No protocol changes — 1.2 talks to 1.1 and 1.0 as before.
